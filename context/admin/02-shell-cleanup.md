# 管理员端应用壳精简

> 状态：已完成（2026-08-05）。本批次属于 A2 业务页面开发前的应用壳清理，不改变后端 API、认证或 OpenAPI 契约。

## 1. 语言范围

- 管理端只维护中文 `zh` 与英文 `en`，中文为默认语言。
- 删除波斯语资源、语言选项和波斯语图标。
- `taxonomy` 作为内部路由、Capability 和 API 标识保留；中文用户界面统一显示“分类”。
- RTL 仍作为独立的布局偏好保留，不再由语言切换自动推导。

## 2. 视觉偏好

- 主题色只允许预设色，保留现有七个预设。
- 默认主题色为首个预设 `#009b43`。
- 删除自定义颜色输入及其运行时更新逻辑。
- 卡片固定采用当前默认的扁平边框样式，删除 `flatDesign` 状态、开关和持久化字段。
- 删除浏览器 Fullscreen API 按钮和相关埋点；布局中的无调用 `fullScreen` 属性同步移除。

## 3. 兼容迁移

启动时归一化 `localStorage.layout`：

- `activeLanguage=fa` 或未知语言回退为 `zh`；
- 历史自定义主题色回退为 `#009b43`；
- 丢弃 `flatDesign` 遗留字段；
- 保留暗色、流体布局、折叠状态和独立 RTL 设置；
- JSON 损坏时使用默认偏好。

## 4. 验收

- 单元测试覆盖语言集合、分类翻译、偏好归一化和预设主题色约束。
- mock/real Playwright 认证链路保持通过；定制面板仅显示预设色，RTL 开关仍可用。
- 管理端 `check`、`typecheck`、单元测试、构建和两套 E2E 全部通过。
